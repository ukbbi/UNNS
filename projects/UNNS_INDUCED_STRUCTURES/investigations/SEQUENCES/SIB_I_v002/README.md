# SIB-I v002 — Arithmetic architecture and complete small-target ancestry

This separate release preserves SIB-I v001. It incorporates and independently
checks the user's research-audit witness at 4096, then tests what prime-exponent
architecture determines about induced geometry.

Run with Python 3.10+ (standard library only):

    python scripts/run_sib.py
    python scripts/verify_sib.py

Or double-click RUN_SIB.bat on Windows. Read reports/RESULTS.md and REGISTER.md.

## Fixed scope

- Unchanged T_N(s)=s(N+1)^2/N, N|s, s,N positive integers.
- Complete ambient ancestry of every target 1<=x<=4096, at every possible depth.
- Forward edges generated by enumerating source divisors; histories propagated
  in increasing target order. Independent backward recursion tests all square
  divisors directly, without using the forward graph or a prime factorization.
- T_N(s)>=4s ensures no history into this target range leaves it. Maximum
  possible depth is 6. The computation includes arbitrary positive sources.
- Empty words are excluded. A history is (source, ordered word). Common-source
  unordered route pairs are classified by their label multisets, with repetitions.
- Distinct external indices remain distinct observations; unique support is also
  reported. Only the portions of the v001 six-sequence panel <=4096 are used.
  These smaller all-depth samples do not replace v001's larger depth-3 benchmark.

## Arithmetic controls

The exponent signature sorts the positive exponents in the prime factorization,
discarding prime identities. The signature of 1 is the empty tuple, called unit.
For each observed x, the control pool contains all integers <=4096 with the same
signature and binary bit length, excluding every observed support value in that
sequence. Exported pools are exhaustive, not random samples. Means weight each
member of a target's pool uniformly; target means are aggregated either uniformly
over unique covered values or by external occurrence multiplicity.

Empty pools are reported and excluded from both sides of the comparison. This
changes the covered population, explicitly recorded in summary.json. No missing
pool is filled by a control with different arithmetic structure. Pools overlap;
the descriptive means are not independent replicates and carry no p-values.

For powers of two with exponent k>=2, this matching scheme has no alternatives
even without the 4096 cutoff. See REGISTER.md V2-04. Consequently it cannot
estimate a controlled excess for the active powers-of-two terms.

## Order controls

Thirty-two fixed-seed permutations per family preserve the complete observed
value multiset. Seed is 20261122 plus family ordinal in the declared order:
Lucas, primes, totient, powers of two, Catalan, Sylvester. Adjacency metrics are
shared incoming labels, shared complete route words, equal values, proper forward
divisibility, and actual legal transitions. Word overlap disregards source identity;
merger classification retains it. No permutation-based significance claim is made.

## Files

- data/: indexed bounded sequence samples.
- results/integer_census.csv: all 4096 profiles.
- results/powers_all_depth.csv: complete ancestry profiles for 2^0 through 2^12.
- results/different_witnesses.csv: one different-content witness per eligible target.
- results/arithmetic_strata.csv and counterexamples.csv: within-stratum variation.
- results/control_pools.csv and matched_controls.csv: auditable arithmetic controls.
- results/order_controls.csv: observed and permuted order metrics.
- results/summary.json and verification.json: conclusions and validation status.
