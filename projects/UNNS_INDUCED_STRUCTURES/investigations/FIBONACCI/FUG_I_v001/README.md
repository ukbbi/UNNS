# FUG-I v001 — Fibonacci Geometry Induced by the UNNS Substrate

**Local research module · 20 November 2026 · EXACT finite enumeration / PROVED background laws.**

**Scope:** Fibonacci indices `1..48`, forward paths of length `1..3` under the explicitly selected integer self-substitution grammar. Intermediate values need not be Fibonacci numbers. The original two-input UNNS arithmetic is not changed.


## Scientific purpose

Place the Fibonacci recurrence **onto** the fixed UNNS operation and analyze the **induced geometry**, rather than compare two arbitrary data sets or infer that UNNS generates the Fibonacci recurrence.

1. **Occurrence geometry:** which distinct UNNS occurrences produce each Fibonacci term?
2. **Transport geometry:** which nest coordinates persist under divisibility of Fibonacci indices?
3. **Actual transition geometry:** which Fibonacci values are connected by legal SELECT-II moves `T_N`, either directly or through non-Fibonacci intermediate integers?
4. **Branching and reconvergence:** do distinct source Fibonacci observations and/or distinct label words reach a common substrate node?
5. **Discrimination:** how do these finite structural patterns differ from selected arithmetic controls?

## Fixed and selected rules

Fixed original primitive (all `M,N>=1`, rational output allowed):

`M ⊥ N = M(N+1)^2/N`.

Explicitly **selected** integer continuation, not forced by the original two-input primitive:

`T_N(x)=x(N+1)^2/N`, for positive integers `x,N` with `N|x`.

External Fibonacci recurrence: `F_0=0`, `F_1=1`, `F_(n+2)=F_(n+1)+F_n`. Only positive-index Fibonacci values are analyzed; repeated value `F_1=F_2=1` retains two external indices.

## Verified finite findings

- `9` of the first `48` Fibonacci index layers have nonempty incoming UNNS occurrence fibres; total incidence points, counting indexed layers separately: `27`.
- The index-meet identity `D_m ∩ D_n = D_gcd(m,n)` passes all `48²=2,304` exact checks and is also a proved general theorem.
- Exactly `1` directed one-step route, `4` two-step routes and `3` three-step routes connect pairs `(F_i,F_j)` with `1<=i<j<=48`.
- These `8` routes cover only `4` distinct ordered pairs: `(3,6)`, `(5,12)`, `(6,12)`, `(3,12)`.
- Concrete reconvergence: `5 -> 36 <- 8`, with different labels, and `36 -> 144`.
- The endpoint `144` has two different two-step histories from `5`, two from `8`, and three three-step histories from `2`.
- No consecutive Fibonacci terms can be connected by any nonempty forward SELECT-II path (proved for **all** indices, not merely verified to 48).

**Important:** Counts are **finite-window exact mathematics**. Their occurrence does not establish that Fibonacci recurrence transitions are generated by `T_N` and does not by itself support a physical inference.
