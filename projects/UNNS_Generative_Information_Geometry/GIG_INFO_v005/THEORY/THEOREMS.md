# GIG-INFO v005 — Forbidden-History Topology: theorem register

Status tags: [PROVED] = proof given here (finite exact checks stated explicitly) · [FINITE-EXACT] = exact computation on a stated finite set · [BOUNDED] = observed on a stated sample · [OPEN] · [FALSIFIED].
Notation: k = 6; P = proper nonempty subsets of [6] (62); T = Δ(P) ≅ S⁴ (order complex); a history = full flag; A = set of admissible histories; Y_A = subcomplex of T generated by the non-admissible flags; K_A = full subcomplex of the permutohedron on A. All homology over GF(2).
Inherited (v004, T-AD, [PROVED], re-verified in v004 on 700 systems): for A proper nonempty, H̃_j(K_A) ≅ H̃^{3−j}(Y_A); in particular **β₂(K_A) = dim H₁(Y_A)**.

## 1. Arithmetic side: β₂(K_A)>0  ⇔  a 1-cycle of a small "dead-set nerve"

**L1 (star-intersection lemma) [PROVED].** For nonempty T ⊆ P let Q_T = {x ∈ P : x comparable (⊆ or ⊇) to every t ∈ T}. Then Q_T = ∅ or Δ(Q_T) is contractible.
*Proof.* Let x₀ ∈ Q_T. Case 1: some t ∈ T has t ⊆ x₀. Put A = ∪{t ∈ T: t ⊆ x₀} (nonempty, ⊆ x₀, so proper). For x ∈ Q_T set φ(x) = x ∪ A. (i) φ(x) is comparable to each t: if t ⊆ x₀ then t ⊆ A ⊆ φ(x); otherwise x₀ ⊊ t, so A ⊆ t, and x ⊆ t ⇒ φ(x) ⊆ t, t ⊆ x ⇒ t ⊆ φ(x). (ii) φ(x) ≠ [6]: if x ⊆ t for some t ∈ T then φ(x) ⊆ t (when x₀ ⊊ t) or φ(x) = A ⊆ x₀ (when t ⊆ x₀, x ⊆ t ⊆ A); if x ⊄ t for all t, then x ⊇ every t, so x ⊇ ∪T ⊇ A and φ(x) = x. So φ is a monotone, extensive, idempotent map Q_T → Q_T, hence Δ(Q_T) ≃ Δ(φ(Q_T)) (Quillen closure lemma); φ(Q_T) = {x ∈ Q_T : x ⊇ A} has minimum A (A ∈ Q_T by the same comparisons), hence is a cone. Case 2: no t ⊆ x₀; then x₀ ⊊ t for all t, V = ∩T ⊇ x₀ is proper nonempty, φ(x) = x ∪ V works identically with minimum V. ∎ (A25: 5,953 sets T tested numerically, including 141 "hard-case" T with ∩T=∅, ∪T=[6]: 4,281 nonempty Q_T all acyclic, 0 failures.)

**T-NERVE [PROVED].** Let 𝒢 be a set of simplices (chains) of T, each *generating*: every flag containing σ is non-admissible, and such that every non-admissible flag contains some σ ∈ 𝒢. Then Y_A = ∪_{σ∈𝒢} St(σ) (closed stars), and Y_A ≃ the nerve whose simplices are the subsets 𝒮 ⊆ 𝒢 for which some z ∈ P is comparable to every vertex of ∪𝒮.
*Proof.* ∩_{σ∈𝒮} St(σ) = Δ(Q_{∪𝒮}); apply L1 and the nerve theorem. ∎

**P1 (arithmetic admissibility is prefix-defined) [PROVED].** With the stepwise rule m ↦ m/ℓ·(ℓ+1)² (ℓ | m required), m_{t−1}/ℓ_t integral ⇔ m ∏_{s≤t}(ℓ_s+1)²/ℓ_s integral (the factor (ℓ_t+1)² is coprime to ℓ_t). Hence an ordering is admissible iff every prefix set I satisfies m·∏_{ℓ∈I}(ℓ+1)²/ℓ ∈ ℤ: a property of the set I alone. [FINITE-EXACT: re-checked by `nerve.is_prefix_defined` on all 1,290 tested masks and both certified pairs.]

**C1 (dead-set nerve) [PROVED, from L1, T-NERVE, P1, T-AD].** For an arithmetic regime let D_A = {I ∈ P : every flag through I is non-admissible} (dead sets; all forbidden prefix sets are dead). Take 𝒢 = {{I}: I ∈ D_A}. Then Y_A ≃ N[D_A], where N[D] = {T ⊆ D : ∃ z ∈ P comparable to all of T} (edges = all pairs except complementary pairs I, [6]∖I), and
  **β₂(K_A) = dim H₁(N[D_A]) = dim H̃₁(N[D_A]).**
Also β₁(K_A) = dim H̃₂(N[D_A]) and (reduced) b₀-parts correspondingly. [FINITE-EXACT confirmation A20: reduced b₀, b₁ of N[D] equal those of the directly built Y on 290/290 positives and 1,000/1,000 sampled negatives.]

**C2 (sufficient criterion) [PROVED].** If N[D_A] contains a 1-cycle z and an edge cocycle c with c(∂τ)=0 for every triangle τ of N[D_A] and c(z)=1, then β₂(K_A)>0. *Certificates:* `RESULTS/A26_cocycle_certificates.json` — 290/290 positives (158 census + 132 held-out regimes) carry such a (z,c), checked by independent code (`nerve.check_cocycle`): 288 with z a hollow triangle, 2 with z a 4-cycle.

**R-A1 [FINITE-EXACT] motif census.** A *hollow triangle* of N[D] is a triple of pairwise non-complementary dead sets with no common comparable set. Among the 290 positives: 288 contain a **non-bounding** hollow triangle (35 S₆-orbit types), the other 2 have a non-bounding 4-cycle X, Y, Y∪{e}, X∪{e} with X ⊔ Y ⊔ {e} = [6] — two *complementary dead-set pairs* {X, Y∪e}, {Y, X∪e} (a "complementary square", the equator of a cross-polytope). Among 1,000 sampled negatives: 707 contain hollow triangles, **0 contain a non-bounding one**. ("Non-bounding" = not in the span of triangle boundaries of N[D].)

The converse fails: 6 (positives) and 105 (negatives) hollow triangles have no cone point yet bound via longer fillings. So the criterion is homological, not a one-vertex local pattern. ## 2. Symbolic side: pairwise transition grammars cannot produce β₂>0

For an ordered pair p = (x,y) let Z_p ⊆ T be generated by flags in which x is immediately followed by y. For S ⊆ pairs let Z_S = ∩_{p∈S} Z_p.

**L2 (description of Z_S) [PROVED].** A chain of cuts ↔ ordered partition (B₁|…|B_m), m ≥ 2, with block index b(·). It is a face of a flag with adjacency (x,y) iff b(y)−b(x) ∈ {0,1}. Hence Z_S = {ordered partitions with b(y)−b(x) ∈ {0,1} ∀(x,y)∈S}; Z_S ≠ ∅ iff the digraph S is not strongly connected on the six events. [FINITE-EXACT check of the nonemptiness criterion on all |S|≤3 and 300 random larger S: 0 violations; adjacency description of Y vs direct Y: 40/40 random systems identical.]

**T-ADJ (pairwise-adjacency theorem) [PROVED, computer-assisted].** Let G be any digraph on six distinguishable events and A the set of its Hamiltonian paths (A ≠ ∅, A ≠ all). Then **β₂(K_A) = 0.** In particular every S/R/N rule set, with any multiset of categories.
*Proof.* Let B be the set of bad ordered pairs. Y_A = ∪_{p∈B} Z_p (every non-admissible flag contains a bad adjacency; every flag with a bad adjacency is non-admissible). The Mayer–Vietoris (Čech) spectral sequence of this cover has E¹_{p,q} = ⊕_{|S|=p+1} H_q(Z_S) ⇒ H_{p+q}(Y_A); total degree 1 involves only E_{0,1}, E_{1,0}, and no differential touches E_{1,0}. Finite exact checks (`B20`, GF(2) elimination): (a) for all 30 ordered pairs Z_p has H̃₀=H̃₁=H̃₂=0; (b) for all 435 pairs of pairs Z_{pq} ≠ ∅ and connected; (c) for all 4,060 triples Z_{pqr} ≠ ∅ (120 of them are disconnected, which is harmless: each component maps to the same boundary class). Then E¹_{0,1} = 0, E¹_{1,0} = F₂^{pairs of B}, and the image of E¹_{2,0} is spanned by the triangle boundaries on all triples of B; so E²_{1,0} = H₁ of the 2-skeleton of a simplex = 0 and H₁(Y_A)=0. T-AD gives β₂(K_A)=H₁(Y_A)=0. ∎
Consequences: the v004 observation β₂=0 in 565,000+ symbolic systems is a theorem for this whole class. [FINITE-EXACT B24: all 665 distinct nonempty proper S/R/N masks (28 multisets × 512 rules): β₂=0; β₁ takes values {0:616, 2:42, 6:6, 8:1}; β₃=0; direct H₁(Y)=0 on 150 samples.] The v004 conjecture "H₁(Y)=0" is therefore **resolved positively for pairwise grammars**; β₁ (= H̃₂(Y)) is *not* restricted (it is positive in 49 of the 665 masks).

**S-3 (sharpness) [FINITE-EXACT, certified counterexample].** Admissibility by consecutive **triples** breaks the theorem: forbidding exactly the two consecutive triples (1,2,0) and (5,4,3) gives N=674 and Betti numbers (1,2,5,0,0,0) — β₂ = 5, certified by two independent rank routes and an explicit cycle/cochain pair verified by definition-level code (`CERTIFICATES/counterexample_triple_adjacency_beta2.json`). Mechanism (B23, Mayer–Vietoris): Z₁ and Z₂ are H̃₀=H̃₁=0 but Z₁∩Z₂ has six components, so H₁(Z₁∪Z₂) ≅ H̃₀(Z₁∩Z₂) = 5. Random 3-adjacency sampling: 905 of 19,993 systems have β₂>0 (B22, exploratory, not pre-registered).

## 3. What decides recoverable topology (answer to the v005 question)

* **Arithmetic (prefix-forbidden histories).** Forbidden histories are *sets* I (prefix subsets); the relevant structure is the nerve N[D] on the dead sets. β₂>0 ⇔ N[D] has a 1-cycle; the cycles seen are hollow triangles (288/290) or complementary squares (2/290). These arise because the divisibility thresholds produce dead sets that are pairwise "compatible" (non-complementary) but have no common comparable set.
* **Symbolic pairwise grammar (forbidden adjacencies).** Any three adjacency pieces always meet and any two meet in a connected set, so no 1-cycle can form: β₂=0 unconditionally.
* **Locality order.** Adjacency constraints of order 2 ⇒ β₂=0 (proved); order 3 ⇒ β₂ can be positive (S-3). Prefix-set constraints ⇒ β₂ can be positive (arithmetic). The dividing line is *how local* the forbidden pattern is in the history, not integer divisibility.
* **Not established:** a first-principles derivation of S₂; a purely local criterion for hollowness (R-A2); a classification of which digraph-set families give β₁>0.
