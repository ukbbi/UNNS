# GIG-I v002 — Definitions

All definitions of GIG-I v001 (`../GIG_I_v001/THEORY/DEFINITIONS.md`) are inherited unchanged. New or sharpened notions:

**Setting.** `T_N(m)=m(N+1)²/N` for `N | m`; `R(N)=(N+1)²/N`. A *content* `C` is a set of `k` **distinct** labels, written in increasing order `c_0<…<c_{k-1}`. An *arrangement* is a permutation `p∈S_k`; it stands for the word `w_p=(c_{p(0)},…,c_{p(k-1)})`. Bit `i` of every mask corresponds to the i-th permutation of `history_complex.perms(k)`.

**Threshold, realizable sets.** `K(w)` is the frozen threshold (v001 `threshold`): `w` is admissible from `m` iff `K(w) | m`. `A_C(m)={p: K(w_p)|m}`. `S⊆S_k` is *realizable* (for `C`) if `S=A_C(m)≠∅` for some integer `m`.

**Exponent tables / level sets.** `K(w)=∏_q q^{e_q(w)}`, `e_q(w)=max(0, max_j −Σ_{i≤j}Δ_q(N_i))`, `Δ_q(N)=2v_q(N+1)−v_q(N)`. `M_{q,e}={p: e_q(w_p)≤e}`. Then `A_C(m)=⋂_q M_{q,v_q(m)}`.

**Arithmetic closure (T12).** `L(S)=lcm{K(w):w∈S}`, `cl_K(S)={v: K(v) | L(S)}` (v002 uses `ContentClosure`, which computes it through the level sets).

**Generator-coloured swap graph.** `G_A` = induced subgraph of the permutohedron graph on `A⊆S_k`; the edge between `p` and `p·s_j` (swap of positions `j,j+1`, `j=1..k-1`) has *colour* `j`. The *uncoloured* swap graph forgets the colours (and, as always, labels and arrangements). A *Coxeter-diagram automorphism* of `A_{k-1}` is `id` or the reversal `j↦k−j`.

**Faces / parabolic cosets.** A face of `P_k` is an ordered set partition `(B_1|…|B_r)`; as a vertex set it is a left coset `x·W_J`, where `J⊆{1..k−1}` is the set of colours *inside* the blocks (`|J|=dim`), and `W_J` is the parabolic subgroup generated by `{s_j : j∈J}`, of order `∏(run+1)!` over maximal runs of consecutive colours in `J`. `K_A` = full subcomplex of `P_k` on `A` (a face is kept iff **all** its vertices lie in `A`).

**Commuting cube.** A face all of whose blocks have size ≤ 2 (`d` = number of 2-blocks). Its vertices are coordinatised by `{0,1}^d` (0 = lower label first in that pair). `Q_3` = a 3-dimensional commuting cube (blocks 2|2|2 inside a k=6 arrangement: 90 of them in `P_6`; each has 8 vertices).

**Cube-product property (CP).** `A∩Q` is a coordinate box `E_1×…×E_d` (`E_i⊆{0,1}`) for every commuting cube `Q`. (T11: every realizable set has CP.)

**Cycle types in `P_k`.** `braid-hexagon` (a 2-face of type 3-block), `cube-petrie` (chordless 6-cycle in a commuting `Q_3`, i.e. the cube minus two antipodal vertices), `cube-domino` (boundary of two squares sharing an edge, inside a `Q_3`), `mixed-domino` (two squares sharing an edge with colour set `{i,i+1,j}`), `other` (none exists for `k≤8`).

**Information levels (hierarchy of v002).**
`uncoloured swap graph  →(add colours)→  coloured swap graph  →(components of size |W_J|)→  face poset of K_A  →  Betti numbers.`
`I_r` and every v001 accessibility signature live on the first level.
