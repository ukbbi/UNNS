# GIG-INFO v002 — Entropy–Topology Separation Across Generative Systems
Sibling of GIG_INFO_v001 and GIG_I_v001–v007 (all frozen, read-only; nothing in them is modified).

Headline (bounded to the six-label census, 346,859 systems): the history count N does **not** determine whether β₂>0 (H(Y|N)>0; 72 same-content and 326,912 cross-system equal-N pairs), but ball-2 accessibility histograms added to N, or the full f-vector, remove all uncertainty (H(Y|·)=0 in every ensemble).
