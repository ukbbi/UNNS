# Final closure changes, GIG_MANUSCRIPT_v002
Made in response to the independent review. The mathematics, structure, figures and authorship are unchanged apart from the two scope corrections below.

1. Manifest and PDF. `MANIFEST.json` now lists the distributed PDF under its actual name, `GIG_Manuscript_v002.pdf`, and covers every file of the package except itself; `tools/check_manifest.py` recomputes all hashes.
2. Portable cross-references. Every label inside a theorem-like environment now carries an explicit cleveref type (`\label[lemma]{...}` etc.) and the appendix labels are typed `appendix`, so "Lemma", "Definition" and "Appendix" names no longer depend on the TeX distribution's handling of shared counters.
3. Build. `build.sh` no longer suppresses errors (`|| true` removed), uses `-halt-on-error`, fails on undefined references, and does not run the authoring tool.
4. Verification. `verify/run_all.sh` runs all five check scripts and the stand-alone certificate checker with the certificate path supplied. The nerve helpers used by `run_checks5.py` moved into `verify/nerve_tools.py`, so verification needs only the Python standard library (tested with matplotlib and numpy blocked). BUILD.md corrected.
5. Scope correction, uncoloured graph. The text no longer says that the uncoloured swap graph cannot determine beta_2. What is proved: it fixes f_0, f_1, f_2, rho_1, rho_2 and hence beta_0 and beta_1 (prefix-defined, k<=8), and beta_2 up to rank of the third boundary map. Whether graph-isomorphic realizable systems can differ in beta_2 is not settled; none was found. Fig. 9.1: the beta_2 / O_G cell is now "open"; the anchored-state / O_C cell, which no result covers, is also "open". The anchored-state failure at the uncoloured graph is the finite-exact Proposition 9.3 and is unchanged.
6. Scope correction, abstract. The abstract no longer says the same survival law holds for every cycle. It says survival is decided by each cycle's own minimal filling families, and that the four families and the gcd condition are particular to the anchors.
7. Provenance. `records/THEOREM_SOURCE_INDEX_v002.md` lists, for each of the 106 labelled statements, the provenance recorded in v001 and links to the release folders at commit a115e4bc6b8ee734e6146b3b17a6b121e65d31c3. 80 statements have recorded provenance; 26 (mostly definitions and notation) say "none recorded". Links were constructed, not fetched, and the folder names other than GIG_I_v005, GIG_I_v005_S2, GIG_I_v005_S3 and GIG_INFO_v006 follow the same naming pattern.
