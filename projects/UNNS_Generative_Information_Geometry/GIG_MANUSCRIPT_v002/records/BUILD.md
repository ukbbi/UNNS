# BUILD, GIG_MANUSCRIPT_v002
Requirements: TeX Live with pdflatex, lmodern, cmap, tikz, cleveref, hyperref, microtype, booktabs, longtable. Verification needs Python 3 and its standard library only. Regenerating figures (`python3 figures/make_figures.py`) additionally needs matplotlib and numpy; the verification scripts do not.

1. Build the PDF: `./build.sh`. It runs three `pdflatex` passes on `main.tex` with `-halt-on-error`; any LaTeX error or undefined reference stops it with a non-zero status, and a successful build prints `BUILD_OK`. The sources are `src/*.tex`. (`tools/compose.py` is an authoring tool that regenerates `src/` from `tpl/` and the preserved v001 sources in `tools/v001_src/`; it is not part of the build. It gives every label inside a theorem-like environment an explicit cleveref type, so cross-reference names such as "Lemma 2.3" or "Appendix A" do not depend on how a TeX distribution resolves shared counters.)
2. Verify: `./verify/run_all.sh` runs `run_checks.py` ... `run_checks5.py` and then `python3 inherited/standalone_verify.py --cert inherited/positives_cycle_cocycle.json` (expected final line `ALL PASS`). The stand-alone checker needs the `--cert` argument in this package layout; run alone as `python3 verify/inherited/standalone_verify.py --cert verify/inherited/positives_cycle_cocycle.json`. A recorded run is `verify/verify_v002_final_run.txt`; the corrupted-certificate test is `verify/tamper_v002_run.txt`.
3. Authenticate the package: `python3 tools/check_manifest.py` recomputes every sha256 in `MANIFEST.json`.
4. Page audit: `tools/sheets.sh` renders contact sheets of all pages into `pages/`.
