# GIG-INFO v003 — Second-Neighbourhood Information and Topological Recognition
Sibling of GIG_INFO_v001/v002 and GIG_I_v001–v007 (frozen, read-only).

Headline. (1) Proved: |B2(w)| = 1 + d + sum_{u~w}(d(u)-1) - q(w); hence sum|B2| = N + sum d^2 - 4*squares. (2) On the six-label census, (N, sum|B2|^2) and, more interpretably, (squares, sum_w s(w)^2) separate beta2>0 from beta2=0 exactly; adding the single scalar sum_w s(w)^2 to (N,h1) resolves all 66 positives that radius 1 leaves unresolved. (3) A certified same-content witness (content (2,4,5,9,14,15), sources 2520/3780) has equal N, h1, square profile and mean |B2| but different h2 and beta2. (4) Pre-registered held-out test on 263,124 new six-label regimes: (squares, sum s^2) and (sum d^2, sum s^2) held; (N, sum|B2|^2) did NOT (prediction falsified). (5) Seven-label sample too small to say anything.
