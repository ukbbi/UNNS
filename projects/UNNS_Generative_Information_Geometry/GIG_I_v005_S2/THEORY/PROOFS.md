# GIG-I v005 Stage 2 — proofs / verification
AT-1: the faces of X_λ(m) are those F of P_6 with Pref(F) ⊆ A(m) (T16/T17). So z ⊂ X iff P_z ⊆ A(m), and z bounds iff it lies in the GF(2) span of ∂_3 of the present 3-faces; this depends on A(m) only through A(m) ∩ (63 sets) and is monotone in it, hence determined by the antichain of its minimal bounding supersets of P_z.
Exactness of the antichain: f(S)="z bounds with P_z ∪ S" is monotone. S is true iff S meets the complement of every maximal false point, so the minimal true points are the minimal transversals of those complements. The algorithm alternates Berge dualisation with greedy extension of a false transversal to a maximal false point; it stops only when every minimal transversal tests true (then each is a minimal true point, and every true point contains one). E23 stats record the number of bound tests; tests/test_s2 compares with brute force 2^q on two q ≤ 14 classes and with Stage 1's 2^20 enumeration.
