# Proposal (not a registration): U4-GEN — when does branching admit an independently specified selector?
Starting point: E1 (branching abundance) and E5 (finite-state deterministic ⇒ zero entropy). The decisive question is therefore about *unbounded intrinsic state*.
Predeclared candidate classes, each to be registered with grammar, starts, horizon, escape bound and certification policy before any run:
1. **Metric-history selectors:** choose among admissible successors using d(x_n, x_{n−k}) for k ≤ K, with K a declared constant (then E5 applies) and K growing with n (genuinely unbounded; charged in the ledger as an unbounded observation).
2. **Vertex-as-state selectors:** state = the current vertex (unbounded integers), target-independent rank rules on neighbourhood values/degrees (as in Stage 2D) but on hub-rich starts, measuring whether returns to hubs occur and which branches are taken.
3. **Coded baseline:** an external branch word of length n costs n log b bits; any mechanism claiming to beat the baseline must show its information source.
Questions: (a) can any class in 1–2 revisit a hub infinitely often with a non-eventually-periodic branch sequence? (b) is there a proved obstruction (a pigeonhole-type no-go for K-bounded metric history, plus an analysis of unbounded K)? (c) which of the other open U4 sketches (U4.1-T2/T4/T5, U4.4-T1/T2, U4.5-S2d) are touched by branching?
No result of this proposal is claimed.
