# Adapters

The primary preregistered adapter is specified in:

`ADAPTER_SPEC.md`

It constructs one label-blind 128-level `SYSTEM_SPECTRUM` per algebraic system.

No chamber-specific tuning is performed.

## Historical-name note

`ADAPTER_SPEC.md` was frozen before the first chamber run under the provisional project name
`UNNS_TRACEABILITY_PHENOTYPE`.

It is intentionally preserved unchanged because its SHA-256 hash is part of the freeze record.

The current project identity is:

`UNNS_ADMISSIBILITY_PERCOLATION`

The adapter itself has not changed.
