# Refinement and Saturation Terminology

This project uses **Riesz refinement** for the 2x2 matrix property.

For the rank-one theorem, **lattice saturation** means the standard affine-semigroup construction

\[
\operatorname{Sat}_{lat}(H)
=
(\mathbb R_{\ge0}H)\cap\operatorname{gp}(H).
\]

For \(H\subseteq\mathbb N_0\) this is simply

\[
\gcd(H)\mathbb N_0.
\]

The phrase **lattice saturation** is used deliberately. Some numerical-semigroup literature uses the term "saturated numerical semigroup" for a different condition, so the shorter word "saturated" should not be used without qualification in this project.
