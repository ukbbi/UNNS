# SPEC v014
code/scale_lift.cpp: exact d_{G_W}(A n, A(n+1)), W = M(n+1), by exact radius-R balls from both ends (last layer values only); range mode `scale_lift A M nlo nhi out [R=3] [threads]` (one digit per n, 9 = > 2R); list mode (env NLIST=file) prints "n d" (9999 = > 2R); path mode (env PATHS=1) prints "n d v0..vd". Needs a sieve to max(sqrt(M(nhi+1)), nhi+2).
code/run_sweep.sh: chunked sweep n=1..999999 at A=4 -> results/sweep_A4/ (digits). code/run_exc.sh, run_exc2.sh: exact distances on the exception list (A=4 R=4, A=1 R=4 on all; A=18 R=4 only on the 640 with tau^4=8; A=361, 7600, 160000 R=3). run_exc.sh was interrupted during its scale-18 run (too slow on all 8655) and replaced by run_exc2.sh for the remaining scales.
code/scale_graph.py: BFS in G_B (scale-transfer distances). code/summarize14.py: all statistics from stored data -> results/SUMMARY_v014.json. code/errata.py: v013 parity erratum data -> results/ERRATA_parity.json. code/obs_rho.py -> results/OBS_rho.json. code/verify_all_v014.py [--quick]. Other code files are copies from v013.
results/EXC_A4_gt6.txt (the 8,655 exceptions), results/EXC_A4_eq8.txt (the 640), results/exc/*.txt (per-scale distances), results/ROUTES_v014.json (300 explicit routes at scale 10^6).
Provenance note: the sweep and exception files were produced by binaries compiled from this scale_lift.cpp before the path mode (PATHS) was added; the range/list code path is unchanged and the verifier rebuilds slices from the packaged source.
