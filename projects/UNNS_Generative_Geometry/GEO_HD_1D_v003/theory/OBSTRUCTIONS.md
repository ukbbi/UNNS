# OBSTRUCTIONS -- Stage B, part 2: D-Q1, classification of disconnected swap classes by resource contention

Statuses as in THRESHOLDS.md. Same-author caveat; C3 NOT claimed. Fixed-source scope.

## The mechanism, stated once
By the prefix-set form (THRESHOLDS.md, (P)) a history is a maximal chain of feasible subsets, and a set S is infeasible at m iff for some prime p: sum_{x in S} Delta_p(x) < -v_p(m). So the swap graph is governed by the family F(m) of infeasible proper subsets: a set is infeasible when it consumes more of some prime than m supplies plus what the members themselves produce. Two chains are swap-connected only through feasible subsets. A disconnection is therefore a *deadlock pattern*: groups of labels none of which can be completed first.

## Theorem T3 -- exact classification for three distinct labels (PROVED; closes the v002 open item "classification of split contents with 3 labels")
Let C = {x,y,z} (distinct). The swap graph of C at source m is disconnected iff there is a labeling (a,b,c) of C such that
   a | m, c | m, kappa{a,b} | m, kappa{b,c} | m, kappa{a,b,c} | m,   and   b does not divide m, kappa{a,c} does not divide m.
In that case A(m) = {(a,b,c), (c,b,a)} exactly (an antipodal pair of the hexagon), there are exactly 2 classes, and a content has a split source iff for some labeling L = lcm(kappa{a}, kappa{c}, kappa{a,b}, kappa{b,c}, kappa{a,b,c}) is divisible by neither b nor kappa{a,c}; the minimal split sources are these L, and the split sources of that labeling are the multiples m of L with b not| m and kappa{a,c} not| m.
*Proof.* The arrangement graph of three distinct labels is a hexagon. (<=) abc has prefix sets {a},{a,b},C and cba has {c},{c,b},C, all feasible; acb and cab have the prefix set {a,c}, bac and bca have the prefix set {b} (note kappa{b}=b), all infeasible; so A(m) is the antipodal pair, which is disconnected. (=>) Let A(m) be disconnected and u, w in different components. If dist(u,w)=2, their unique common neighbour v arises from u and w by two swaps at different positions, so its prefix sets are prefix sets of u or of w; by (P) v is admissible, contradicting that u and w are in different components. Hence every pair from different components is antipodal. A component with two adjacent vertices v, v' would need a vertex of another component antipodal to both, but the antipode is unique per vertex; so components are singletons, and a third component would have the same antipode. So A(m) = {w, w^rev}, and the other four words being inadmissible forces, since {a},{c},{a,b},{b,c} are prefix sets of the two admissible words, exactly the stated infeasibilities. QED
(Verifier X3: criterion = direct simulation of classes at every closure source, labels < 26 fast / < 41 full, and equality of the minimal split sources with the listed L's; builder census labels <= 40: 9880 contents, 388 splitting, 0 mismatches. Finite-exact data point: labels <= 30, all 127 split sources occur at antipodal pairs; this is now implied by T3.)
Mechanism in words: b alone is infeasible (it consumes something that only a or c produces) and {a,c} together are infeasible (they consume something only b produces); everything else works. The two ends can only be run "through" b.

## Parameter family {2,3,N} (PROVED, both directions)
{2,3,N} (N >= 4, N != 2,3) has a split source iff N = 2 or 3 (mod 6) and N >= 8; then N itself is the minimal split source (v002 D-T9(a); minimal split source N re-checked for N < 400). In the language of T3 the middle label is b = 3 when N = 2 mod 6 and b = 2 when N = 3 mod 6. The converse is the corollary of the block factorisation F2 (CONNECTIVITY.md): if N is outside the residue classes the feeding digraph has blocks {2,3}, {N} and no block has three labels. This upgrades v002's FINITE-EXACT converse to PROVED.
Resources: a label x = 2 mod 6 consumes the prime 2 (v_2(x) >= 1, Delta_2 < 0) and produces the prime 3 (3 | x+1, Delta_3 > 0); a label x = 3 mod 6 consumes 3 and produces 2. These two classes are exactly what feed each other; every other label is either independent of them or feeds only one way.

## General statements for >= 4 labels
* **Necessary condition (PROVED, distinct labels).** A split needs a block of the feeding digraph with at least 3 labels (CONNECTIVITY.md). Census: 3 labels (<= 30), 4 labels (<= 14), 5 labels (<= 10): 0 splitting contents without such a block.
* **Sufficient conditions for no split (PROVED).** Acyclic feeding digraph (F1); hub-descent; or any content where each block has <= 2 labels.
* **F2 reduces the classification to strongly connected blocks:** the class count of a content at m is a product of class counts of its blocks at chained entry states.
* **Contention pattern found for k >= 4 (arithmetic part FINITE-EXACT, topological consequence PROVED in ROUTE_TOPOLOGY.md).** For C = {2,3} u X with X a set of labels n >= 8, n = 2 or 3 (mod 6), and source m = prod X, the infeasible proper subsets are exactly the complementary pair E = {x in C : x = 2 mod 6} and O = {x in C : x = 3 mod 6}. (1702 contents with |X| <= 4 checked in the builder, 120+ in the verifier by direct simulation.) For |X| = 1 this is exactly the antipodal pair of T3 (the singleton group is b). In general it is a *complementary-pair deadlock*: neither group can be finished first, every interleaving works.
* **Not classified (OPEN).** An exact classification of splits for >= 4 labels (what families of infeasible subsets F(m) give a disconnected chain graph), and how large the number of classes can be (observed maxima over lcm-closure sources: 3 labels 2 (a theorem, T3); 4 labels 4 for labels <= 18; 5 labels 3 for labels <= 11 and 7 in the targeted family {2,3} u 3 labels n >= 8, n = 2,3 mod 6, <= 44 -- data-limited).
* **Repeated labels.** F2 and the prefix-set form hold for repeated labels (sub-multisets), but the hexagon argument of T3 does not carry over; no classification is claimed.
