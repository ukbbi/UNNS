# HD-C3 / HD-C4 — occurrence events along histories

d is a member of D(m) iff v_p(m) >= 2 a_p for all p | d (half-spaces in valuation space).  rho_d(h) is the incidence sequence along a history, V_d its total variation, chi_d = (V_d - |rho_end - rho_start|)/2 the reduced churn.
**B-T7 (PROVED).** (i) chi_d <= floor(l/2) for a history of length l. (ii) An adjacent swap changes only one state, so |chi_d(h) - chi_d(h')| <= 1. (iii) If every label of h has Delta_p >= 0 for the primes of d, rho_d is nondecreasing and chi_d = 0 (e.g. h_A = 1^7). (iv) Dip lemma: if v_p dips at least 2 below its start and ends at or above it, then chi_{p^floor(a/2)} >= 1.
**B-T8 Necessary churn of the {1,2,3} merger (PROVED; verified for every source v2<=12, v3<=8 and every arrangement).** h_A = 1^7 has chi_d = 0 for all d.  For EVERY source and EVERY arrangement of 2^2 3^4, some d has chi_d >= 1.  Proof: the v3-coordinate is a walk with steps +2 (twice) and -1 (four times) from b back to b.  Case 1: the walk reaches b+2: then d = 3^{floor(b/2)+1} is born and lost (2*floor(b/2)+2 <= b+2).  Case 2: the walk stays <= b+1; its first step must then be -1 and it dips to b-1 or lower.  If b is even the top level of d = 3^{b/2} is b, so d is lost.  If b is odd and the walk reaches b-2 or lower, the top level is b-1 and d = 3^{(b-1)/2} is lost.  If b is odd and the walk only dips to b-1, it must return to b by a +2 step and so reaches b+1 = 2*((b+1)/2): d = 3^{(b+1)/2} is born and lost.  Hence *every* endpoint-preserving rewrite between 1^7 and a rearrangement of 2^2 3^4 necessarily creates an occurrence survival gap.  (For the benchmark order and source 4: chi_2(h_B) = 1.)
Cube family (blocks A/B from 4): total churn at source 4 equals the number of B-blocks.  The minimum number of churning indices over all admissible sources/arrangements is 5 (within the tested index set).
