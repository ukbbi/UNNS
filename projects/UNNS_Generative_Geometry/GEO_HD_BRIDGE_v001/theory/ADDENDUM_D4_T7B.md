Family: U_j = {2^4, 3^j}, V_j = {1, 8^2, 3^j}; R(2)^4 = R(1)R(8)^2 = 3^8/2^4; move 2222 <-> any arrangement of {1,8,8}.  a = v2(m), b = v3(m).
**Theorem.** For every j >= 1: both contents are realizable iff b + 8 >= j and (a,b) != (0,0); then the swap-and-rewrite space is connected iff b >= 1 or a >= 4, and otherwise has exactly two components (one swap class per content).
Proof.
* Realizability.  Each 2 adds 2 to v3 and each 8 adds 4; each 3 removes 1: the final v3 is b+8-j >= 0.  a=b=0: U cannot start (2 needs v2>=1, 3 needs v3>=1) and V stalls after the leading 1 (8 needs v2>=3, 3 needs v3>=1).  Otherwise explicit words: b>=1: 3,2,2,2,2,3^(j-1) and 3,1,8,8,3^(j-1); b=0,a>=1 (so j<=8): 2,3,2,2,2,3^(j-1) and 1,8,3,8,3^(j-1).
* One swap class per content.  Lemma: for coprime labels A,B such that every B raises v_p for p | A without consuming it (3 raises v2 by 4) and every A raises v_p for p | B (2 and 8 raise v3), admissible orderings of any multiset {A^s,B^t} from any state are one swap class.  Induction on length: if both first letters are legal, A·r admissible implies the first B of r can be moved to the front of r (it is legal there because A raised v_p(B); the A's it passes only gain resources), giving A·B·r' and B·A·r' (same state), which joins the class starting with A to the class starting with B; each class is connected by induction.  Applied to (2,3) and (8,3); for V_j the label 1 moves to the front by legal swaps (it needs nothing and only raises v2).
* Connectivity.  b>=1: both 3·2222·3^(j-1) and 3·(1,8,8)·3^(j-1) are admissible (after the leading 3, v2 >= 4 and the blocks leave v3 = b+7 >= j-1) with the same endpoint, so the block replacement joins the two swap classes.  a>=4, b=0 (j<=8): 2222·3^j and 188·3^j are admissible.
* Obstruction (3 ∤ m, v2(m) <= 3).  3 can only be applied after v3 has been raised by a 2 or 8.  All 2s of U lie in the block 2222, all 8s of V in the block {1,8,8}; so no 3 precedes either block, the block starts at position 0 with v2 = a <= 3 < 4 (for 2222), and every order of {1,8,8} fails (needs v2 >= 4 or 6).  No redex is ever exposed.
Checked: j <= 16, all (v2<=6, v3<=j) (builder, with the v4 gcd reduction), j <= 16 independently in the verifier, 0 violations.
