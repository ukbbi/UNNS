# G2-H — Synthesis (research statement, not a theory claim)

* Generation → relationships: transport is a linear valuation rule (T2); gain–loss balance and the rewrite law (T3) give the relationship between recombination and loss.
* Relationships → geometry: for integers the geometry is a function of `σ` (T1). Nothing beyond `D` is seen. This is a **collapse theorem**: Level 3 ⇒ Level 4 for integer states.
* Geometry → laws: the only common carrier proved is **σ-transport**: SELECT-II edge `σ'=σ(N+1)/c`; collective regime-I carry `σ→σu`. Both act on the same object but through unrelated multipliers (`(N+1)/c` vs `u` with `t`-dynamics), meeting only in the rigid case (T10), the coincidence family (T12) and the `N=1` obstruction (T13).
* **There is no common law** established: no Level-5 correspondence, no unified rule producing both. What exists: a proved event dictionary in regime I, a finite-exact boundary classification (T11), and exact obstructions (T13).
* Limits of the geometry: loss-budget blindness (O2-5); rational states only sampled (O2-3).
