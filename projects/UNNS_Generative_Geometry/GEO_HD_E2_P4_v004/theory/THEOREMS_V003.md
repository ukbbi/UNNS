## P4-S2  Complete slab characterization for targets with a free coordinate  (PROVED, elementary)
Let Lambda' be a lattice of Z^3 with e_i in Lambda' (free coordinate i), q_i >= 1, Lambda'_2 = Lambda' cap {z_i = 0}, Q' the planar box.  Let U0(Lambda'_2,Q') be the planar union of Graver cells whose corners all lie in
Lambda'_2 cap Q' (the origin IS allowed as a corner); U(Lambda'_2,Q') is the same with corners in F (origin excluded); U <= U0.  Then
   U(Lambda',Q) = [ U(Lambda'_2,Q') x [0,1) ]  union  [ U0(Lambda'_2,Q') x [1,q_i] ]   (coordinate i being the second factor).
*Proof.*  Graver elements of Lambda' are (g,0), g Graver in Lambda'_2, and +-e_i (P4-S1 proof).  A cell is either C2 x {c} (no e_i) or C2 x [c,c+1] (with e_i), c an integer, 0 <= c, with C2 a planar Graver cell.
Corner condition: for c >= 1 the corners (v',c),(v',c+1) are nonzero for every v' in Lambda'_2 cap Q', so C2 may have the origin as a corner; for c = 0 the corners (v',0) force v' != 0, i.e. C2 is a cell of U(Lambda'_2,Q'), and (v',1) is nonzero.
Taking the union over cells: the level t in [0,1) is covered exactly by the cells with c = 0 (type C2 x [0,1] and C2 x {0}), giving U(Lambda'_2,Q'); levels t in [1,q_i] are covered by C2 x [c,c+1] with c >= 1 (and C2 x {1} if q_i = 1) giving U0 (the level t = 1 is also hit by the c = 0 cells, whose slice U is inside U0).  QED
**Corollary P4-S2.a (decision reduction).**  For a source cell C: C <= U(Lambda',Q) iff proj_i(C cap {z_i <= 1}) <= U(Lambda'_2,Q') (when C has points with z_i < 1) and proj_i(C cap {z_i >= 1}) <= U0(Lambda'_2,Q'): a planar problem.
(Closedness of the planar unions makes the closure of the half-open slice the right test.)  This is implemented as `src/free_axis.py` (pinned splitting procedure applied to the two truncated cells against cylinders over planar cells).  Failure of the first part is an "S0 failure" (the v002 slab obstruction); failure of the second an "S1 failure".
**Corollary P4-S2.b (converse of P4-S1.a).**  Within targets that have a free coordinate: U <= U' iff there is no S0 failure and no S1 failure.  The v002 slab criterion is therefore the complete obstruction law *up to S1 failures*, and no S1 failure occurs in any run recorded here.
*Not proved:* that S1 failures never occur.  The natural reason would be "origin-allowed cells cover the hull", and that statement (P4-H0) is **FALSE**: Lambda = E_2, box (1,2): conv{(0,0),(1,1),(0,2)} contains points (e.g. (1/3,2/3)) not covered by origin-allowed Graver cells (`results/P4_H0_TEST_8_5.json`, 215 of 917 planar runs).
