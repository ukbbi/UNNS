# SS23_B4 - YM-3B Class B inputs

Four published `A1++ / 0++` ground-state effective-mass trajectories from Sakai & Sasaki (2023).

Folders:

- `digitized/` - publication-derived M_eff points and graphical error bars.
- `calibration/` - exact source-page, panel, axis, render, and extraction records.
- `native/` - reconstructed normalized variational-eigenvalue proxies on native t/a.
- `common/` - primary seven-point physical-time inputs for CORR-I.
- `common_pchip/` - preregistered interpolation-sensitivity inputs.

`common/ss23_B4_all.csv` is the four-channel batch-ready wide CSV.

These are **Class B published-figure reconstructions**, not raw author correlator matrices.
