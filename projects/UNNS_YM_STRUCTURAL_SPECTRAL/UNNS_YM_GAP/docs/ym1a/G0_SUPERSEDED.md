# G0 status

The original `YM1A-G0` construction is retained for provenance only.

It is superseded for the vacuum-boundary experiment by `YM1A-G0.1`, because
the original five-positive-level common-offset family did not include an
explicit vacuum node and therefore left STRUC-I's adjacent-gap geometry
unchanged under uniform translation.

Use `docs/ym1a/G01_SPEC.md` and `nulls/ym1a_g01/` for all G1 work.
