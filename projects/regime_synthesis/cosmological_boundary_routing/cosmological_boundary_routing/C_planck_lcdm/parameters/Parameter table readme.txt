
PDF parameter tables are provided in various formats, with 68pc, 95pc and 99pc
in the file name denoting 68%, 95% and 99% limits respectively.

Note that some nuisance parameters have slightly difference definitions in the plikHM and CamSpecHM likelihoods.

* result_table_2018_xxpc.pdf

Full tables of results, for all grid chains

* baseline_params_table_2018_xxpc.pdf

Baseline results using plikHM_TTTEEE_lowl_lowE likelihoods (aka. Planck TT,TE,EE+lowE)

* CamSpec_table_2018_xxpc.pdf

Results using the alternative CamSpecHM likelihood, which can be used to assess
differences due to an alternative polarization efficiency model (plus other small differences)

* compare_plikHM_xxpc.pdf

Results for both plikHM and CamSpecHM likelihoods, with CamSpecHM results including
the sigma shift from equivalent plikHM results

* compare_plikTTlowllowE_xxpc.pdf

Results for both plikHM and CamSpecHM showing parameter difference is sigma with respect
to the plikHM_TT_lowl_lowE data combination results

* compare_TTTEEE_TT_xxpc.pdf

Results for both plikHM and CamSpecHM showing parameter difference is sigma with respect
to the equivalent result when replacing TTTEEE with TT

* plikCamSpec_combined_xxpc.pdf

Results from joining, with equal weight, plikHM and CamSpecHM result chains.

* pol_shift_sigma_table.pdf

Results, including the sigma of the shift going from TTTEEE to TT results using the
fact that TT should be a subset of the TTTEEE data, assuming Gaussian errors, and using
the change in the variance to get the standard deviation of the expected shift.

* pliklite_compare-pliklite_TT_lowl_lowE_68pc.pdf

Test results for various multipole cuts based on the plik_lite likelihood, used in the section
of the parameter paper about LCDM parameter consistency, with parameter difference is sigma with
respect to the pliklite_TT_lowl_lowE data combination.

* sigma8-omm-plikHM_TTTEEE_lowl_lowE_lensing-table.tex

A reference table of baseline 68% plikHM TTTEEE+lowl+lowE+lensing constraints on \sigma_8 \Omega_m^x parameter combinations.

This is updated 3.01 version (corresponding to v2 of the arxiv paper), with results for
DES, BK15 and updated Pantheon.
