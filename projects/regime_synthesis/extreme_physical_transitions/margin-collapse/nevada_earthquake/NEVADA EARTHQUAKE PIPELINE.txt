------------------------------------------------------------
PIPELINE
------------------------------------------------------------

STEP 1 — SAC → CSV
------------------

Run:

    python sac_to_csv.py .

This converts all:

    *.SAC

files into:

    *.csv

waveform datasets.

------------------------------------------------------------

STEP 2 — CSV → DELTA LADDERS
----------------------------

Generate ΔA ladders from waveform amplitudes.

Transformation:

    ΔA(i) = A(i+1) - A(i)

Outputs stored in:

    delta_ladders/

------------------------------------------------------------

STEP 3 — STRUC_PERC
-------------------

Run STRUC_PERC on generated ladders.

Outputs stored in:

    struc_perc_output/

------------------------------------------------------------

STEP 4 — STRUCTURAL ANALYSIS
----------------------------

Inspect:

    • admissibility class
    • giant component persistence
    • fragmentation behavior
    • tail dominance
    • station coherence

------------------------------------------------------------
EXPECTED OUTPUT TYPES
------------------------------------------------------------

Typical structural regimes:

    • FULL_PERCOLATION
    • GIANT_COMPONENT_PERCOLATION
    • HARD_FRAGMENTATION
    • TAIL_FRAGMENTATION

------------------------------------------------------------
CORE OBSERVABLE
------------------------------------------------------------

Primary observable:

    ΔA seismic waveform transitions

derived from:

    broadband vertical seismic traces (BHZ).
