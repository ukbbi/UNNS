## Overview

`regime_synthesis/` is the principal cross-domain research archive in the UNNS repository.

It brings together independently developed research programs that study how physically real systems occupy, preserve, approach, leave, or reorganize within structural admissibility regimes.

This directory is **not one monolithic pipeline**. Each top-level folder is a self-contained research branch with its own combination of source data, provenance, scripts, structural ladders, chamber outputs, validation/falsification tests, figures, dashboards, manuscripts, and local `README.md`.

The common structural vocabulary includes:

- admissibility;
- persistence;
- connectivity;
- fragmentation;
- boundary pressure;
- structural routing;
- recoverability;
- canonical representation;
- recurrence;
- regime transitions;
- non-crossability;
- predictive admissibility.

The intended use is:

```text
regime_synthesis/
        ↓
choose a research branch
        ↓
read that branch's README
        ↓
inspect provenance and pipeline
        ↓
reproduce or analyze the frozen outputs
```

# Cross-Branch Research Themes

## Admissibility versus connectivity

A structure may remain admissible without being fully connected under a particular percolation representation:

```text
admissibility ≠ connectivity
```

This distinction appears repeatedly across charge routing, color confinement, galaxy structure, boundary continuity, and other branches.

---

## Internal structure versus external realizability

Several programs distinguish valid internal coordinates from externally admissible states.

The recurring question is not only:

```text
does the structure exist?
```

but:

```text
in what representation and under what closure can it be realized?
```

---

## Boundary approach versus boundary crossing

The archive distinguishes:

- boundary approach;
- finite turning;
- boundary routing;
- representation-induced apparent collapse;
- genuine non-admissibility.

This theme is central to `non-crossability/`, `cosmological_boundary_routing/`, `stellar_boundary_dynamics/`, `charge_boundary_routing/`, and `color_confinement/`.

---

## Representation is structurally active

Examples across the archive include:

- raw versus Δ-lifted neutrino ladders;
- raw versus normalized chemistry trajectories;
- galaxy sampling and radial coverage;
- coarse versus refined helium reconstruction;
- raw supernova observables versus Δmag / curvature;
- magnitude-only versus orientation-sensitive cosmological bridges.

Representation changes should therefore be documented as part of the experiment rather than treated as neutral preprocessing.

---

## Frozen grammar and prospective validation

The later recurrence programs emphasize:

```text
define grammar
    ↓
freeze rules
    ↓
analyze unseen candidate
    ↓
lock verdict
    ↓
reveal ground truth
```

This principle is most explicit in the time-crystal branches but is relevant to the wider predictive direction of the UNNS program.

# Reproducibility and Git LFS

This project archive contains large scientific binary artifacts.

The repository is configured to use **Git LFS** for selected project file types, including:

```text
projects/**/*.zip
projects/**/*.npy
projects/**/*.mp4
```

After cloning:

```bash
git lfs install
git lfs pull
```

Without the corresponding LFS objects, a checkout may contain pointer files instead of the complete binary artifacts.

Some very large upstream raw datasets may remain external or locally referenced where redistribution is unnecessary or inappropriate. Follow the branch-specific provenance documentation.
