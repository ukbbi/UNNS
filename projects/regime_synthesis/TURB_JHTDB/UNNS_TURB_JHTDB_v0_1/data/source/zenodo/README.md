UNNS Turbulence — JHTDB Analysis Cutouts and High-Re Export v0.1

**Concept DOI:** `10.5281/zenodo.22650768`  
**Record:** https://zenodo.org/records/22650769

## Role in the project

Zenodo is the canonical **public archival/distribution layer** for the large frozen source artifacts.

The project continues to use the immutable local working copies under:

`data/raw/jhtdb/`

Do not replace those files merely because the Zenodo copies exist. The Zenodo record provides:

- external recovery if a local copy is lost;
- public reproducibility access;
- a persistent DOI for citation;
- byte-identity checking through the frozen SHA-256 values.

The lightweight project package should continue to omit the multi-gigabyte raw files. It should retain this `data/source/zenodo/` record instead.

## DOI rule

Use the **version DOI** `10.5281/zenodo.22650769` when citing the exact source release used by this project state.

Use the **concept DOI** `10.5281/zenodo.22650768` when a stable link to the archive family/latest version is wanted.
