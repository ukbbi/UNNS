# UNNS Turbulence — JHTDB Analysis Cutouts and High-Re Export v0.1

## Scope

This deposit contains three frozen, JHTDB-derived velocity-field source artifacts used in
the UNNS Turbulence / Johns Hopkins Turbulence Database research project:

1. `isotropic1024-coarse-velocity.h5` — Pilot A.
2. `isotropic1024-coarse-pilot-b-velocity.h5` — independent Pilot B.
3. `HIGH_RE_EXPORT.tar` — the prespecified High-Re source export containing 256^3
   velocity cutouts from JHTDB `isotropic8192` snapshots 0–5 and `isotropic32768`
   snapshot 0.

The deposit is a source-data/provenance record. Derived UNNS structural ladders,
chamber outputs, replication criteria, synthesis documents, and software are not part
of this source-data record and may be archived separately.
