# Attribution and reuse

Underlying data source:
Johns Hopkins Turbulence Database (JHTDB).

License:
Open Data Commons Attribution License (ODC-By) 1.0.

Required attribution should identify JHTDB as the source of the underlying DNS data.
The 1024^3 forced isotropic dataset has upstream DOI `10.7281/T1KK98XB`.

The files in this deposit are selected/extracted JHTDB-derived velocity-field cutouts.
They must not be described as DNS data generated by UNNS.

UNNS contribution:
frozen extraction selection, provenance records, packaging, and checksums.
