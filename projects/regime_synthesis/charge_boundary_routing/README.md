# Charge Boundary Routing

This directory contains the principal research corpus, structural ladders, bridge analyses, transition tests, chamber outputs, figures, dashboards, and manuscripts for the **Charge Boundary Routing** branch of the UNNS Substrate research program.

The project studies a structural distinction between:

- externally observable integer or neutral electric charge;
- confined fractional charge coordinates;
- composite charge closure;
- boundary absences and constrained externalizations;
- allowed and forbidden charge-preserving transitions.

Its guiding question is:

> **Is electric charge best represented only as a value, or does physically realizable charge also follow a constrained structural route from internal coordinates to external closure?**

The preserved research program develops the answer through static layer classification, cross-layer bridge tests, allowed transition corpora, same-charge controls, and forbidden / constrained contrast tests.

## Public research reference

The associated public UNNS article is:

**[Electric Charge Has a Route](https://unns.tech/research/electric-charge-has-a-route)**

# Phase 1 — Charge-boundary classification

Phase 1 separates the corpus into four structural layers.

## Layer A — Primitive External Charge Closures

Purpose:

```text
establish the externally observable integer / neutral charge baseline
```

Representative objects include:

- electron / positron;
- muon / antimuon;
- tau / antitau;
- neutrinos;
- photon;
- W±;
- Z;
- Higgs.

Expected structural classes include:

```text
FREE_INTEGER_CLOSURE
FREE_NEUTRAL_CLOSURE
```

The layer-resolved report records:

```text
signed_charge        → FULL_PERCOLATION
other tested encodings → HARD_FRAGMENTATION
```

and under STRUC-I:

```text
signed_charge → Geometric Persistence / Weak Persistence
```

The project interprets Layer A as the **external charge baseline**, not the complete routing system.

---

## Layer B — Confined Fractional Coordinates

Purpose:

```text
represent quark fractional charge as locally valid but externally non-free
```

Representative objects include:

- up;
- down;
- strange;
- charm;
- bottom;
- top;
- corresponding antiquarks.

Expected classes include:

```text
INTERNAL_FRACTIONAL_COORDINATE
CONFINED_FRACTIONAL_ROUTE
```

The preserved Phase 1 synthesis records:

```text
all six tested Layer B encodings → FULL_PERCOLATION
```

while STRUC-I places all six in:

```text
Structural Boundary / Transitional Structure
```

This distinction is central to the project:

> fractional charge is structurally connected as an internal coordinate system, but is not thereby promoted to a freely externalized closure state.

---

## Layer C — Composite Closures

Purpose:

```text
test whether fractional internal components route into integer or neutral external composite charge
```

Representative objects include:

- proton;
- neutron;
- π± / π0;
- K± / K0;
- Δ++;
- Ω−.

The Phase 1 synthesis records:

```text
all six tested Layer C encodings → FULL_PERCOLATION
```

while STRUC-I again places the isolated layer in:

```text
Structural Boundary / Transitional Structure
```

The interpretation is that composite closure restores connectivity but still carries structural boundary pressure when considered by itself.

---

## Layer D — Boundary Absences and Constraints

Purpose:

```text
mark empirical absences, non-observed externalizations, and constrained exotic boundaries
```

Examples named in the project documentation include:

- free-quark absence;
- free fractional-charge searches;
- magnetic-monopole searches;
- millicharged-particle constraints;
- charge-violation constraints.

Layer D is not treated as an ordinary charge-state ladder.

The Phase 1 synthesis explicitly records that isolated Layer D inputs were not valid ordinary STRUC-I ladders. The project therefore interprets Layer D as a **boundary condition / constraint layer**, not as a failed particle ladder.

---

# Phase 1 conclusion

The preserved synthesis states that the charge-routing structure is **cross-layer**.

In compact form:

```text
Layer A → external charge baseline
Layer B → confined fractional coordinates
Layer C → composite closure
Layer D → empirical boundary / constraint
```

The meaningful structure does not reside in any one layer alone.

# Phase 2 — Bridge geometry

Phase 2 tests how the four layer types connect.

The principal bridges are:

```text
AB
BC
CD
ABC
BCD
```

These bridges distinguish raw charge-value behavior from route / closure behavior.

---

## A ↔ B — External closures to confined fractional coordinates

The AB bridge asks whether ordinary external charge connects directly to fractional internal coordinates.

The preserved result is:

```text
signed_charge / absolute_charge → HARD_FRAGMENTATION
route / closure encodings       → FULL_PERCOLATION
```

while STRUC-I identifies:

```text
absolute_charge → Geometric Persistence / Weak Persistence
```

with other encodings remaining transitional.

Interpretation:

> the external-to-fractional interface is not naturally organized as one raw signed-charge ladder; route and closure coordinates carry the bridge more effectively.

---

## B ↔ C — Fractional coordinates to composite closure

The BC bridge is the central internal-to-composite routing test.

Preserved result:

```text
signed_charge                          → HARD_FRAGMENTATION
route / closure / magnitude encodings → FULL_PERCOLATION
```

All six tested BC encodings remain:

```text
Structural Boundary / Transitional Structure
```

under STRUC-I.

The project therefore describes BC as:

> **route-connected but admissibility-transitional.**

Raw signed charge is not the dominant bridge coordinate.

---

## A ↔ B ↔ C — Composite-mediated bridge

The ABC bridge asks whether composite closure repairs the difficult external/fractional interface.

Preserved STRUC-PERC-I result:

```text
absolute_charge    → FULL_PERCOLATION
closure_class_code → FULL_PERCOLATION
closure_state_code → FULL_PERCOLATION
route_class_code   → FULL_PERCOLATION

boundary_route_coordinate → HARD_FRAGMENTATION
signed_charge              → HARD_FRAGMENTATION
```

STRUC-I keeps all six tested encodings in:

```text
Structural Boundary / Transitional Structure
```

The project therefore treats composite closure as a **partial structural mediator**, not a complete elimination of boundary pressure.

---

## B ↔ C ↔ D — Boundary termination

The BCD bridge tests what happens when the empirically constrained Layer D is attached to the B–C route-connected core.

Layer-D-safe encodings are:

```text
boundary_route_coordinate
closure_class_code
closure_state_code
route_class_code
```

The preserved result is decisive:

```text
all four BCD encodings → HARD_FRAGMENTATION
```

and all remain:

```text
Structural Boundary / Transitional Structure
```

under STRUC-I.

The report summarizes this as:

> **Layer D terminates the B ↔ C route. BCD is BC plus a boundary wall.**

# Phase 2C — Same-charge controls

The workspace contains two important control families:

```text
phase2C_same_charge_control/
phase2C_pairwise_same_charge_control/
```

These controls were introduced to test whether **equal electric charge alone** is sufficient to imply structural equivalence.

The corpus contains route, layer, category, closure, composite, hadron/lepton, boson/fermion, and pairwise difference encodings.

Their purpose is methodological:

> hold charge fixed while varying structural identity, then test whether route geometry still distinguishes the states.

This is an important control against reducing the program to a trivial restatement of charge equality.

# Phase 3C — Forbidden and constrained boundary test

Phase 3C is the negative / contrast experiment.

Its canonical corpus contains:

```text
48 rows
71 columns
```

organized into six groups:

1. allowed controls;
2. charge-violating mocks;
3. free-fractional externalization attempts;
4. selection-rule-violating comparison channels;
5. route-incoherent charge-conserving mocks;
6. constrained / upper-bounded boundary cases.

A crucial design feature is that the corpus distinguishes:

```text
Qi ≠ Qf
```

from the deeper case:

```text
Qi = Qf
but route / closure structure is forbidden, constrained, or incoherent
```

This allows the project to test whether charge conservation by itself is sufficient.

---

## Phase 3C STRUC-PERC-I result

The completed Phase 3C ladders remain globally connected:

```text
42 / 42 completed ladders → FULL_PERCOLATION
0 HARD_FRAGMENTATION
0 isolated nodes
0 tail dominance
```

One low-information control produced no chamber result.

The important conclusion is therefore:

> forbiddenness does not necessarily appear as simple graph disconnection.

Some boundary-related encodings nevertheless require larger connectivity thresholds, especially those connected to free-fractional externalization.

---

## Phase 3C STRUC-I result

Phase 3C produces a much stronger contrast in perturbative admissibility.

The preserved report records:

```text
8  → Geometric Persistence
35 → Structural Boundary
```

with most encodings entering:

```text
Transitional Structure
```

The decisive contrast is the route-transition coordinate:

```text
Phase 3B allowed transitions:
mean Aκ ≈ 0.9851

Phase 3C mixed allowed / forbidden / constrained corpus:
mean Aκ = 0.859238
min Aκ  = 0.8140
```

The report’s principal interpretation is:

> **Charge balance is necessary but not sufficient. Boundary-route preservation is the structural discriminator of admissible transitions.**

This is the core empirical contrast behind the later Boundary-Route Preservation Law formulation.

# Connectivity is not admissibility

One of the strongest methodological lessons in the archive is:

```text
connectivity ≠ admissibility
```

Phase 3C demonstrates this directly.

The mixed forbidden / constrained corpus remains globally percolating under STRUC-PERC-I while losing route-transition persistence under STRUC-I.

Therefore the two instruments answer different questions:

### STRUC-PERC-I v2.5.0

Tests:

- pairwise vulnerability-graph connectivity;
- giant-component structure;
- percolation;
- fragmentation;
- connectivity thresholds.

### STRUC-I v1.0.4

Tests:

- ordered-ladder perturbation response;
- admissibility pressure;
- structural persistence;
- transition toward structural boundary.

The project requires both screens.

# Reproducibility

The intended workflow is:

```text
PDG / source material
    ↓
canonical classification corpus
    ↓
validated structural encoding
    ↓
one-column ladder generation
    ↓
STRUC-PERC-I connectivity analysis
    ↓
STRUC-I admissibility-pressure analysis
    ↓
bridge / transition comparison
    ↓
positive vs negative control synthesis
```

For reproducible use:

1. preserve the canonical source tables;
2. preserve layer identity;
3. do not substitute raw charge values for route / closure encodings;
4. keep STRUC-PERC-I and STRUC-I interpretations distinct;
5. treat Layer D as a boundary / constraint layer rather than an ordinary particle ladder;
6. retain same-charge controls;
7. compare allowed Phase 3B and mixed Phase 3C results directly when evaluating the route-preservation claim;
8. retain source provenance for all PDG-derived fields.

# Scientific scope

This directory does **not** claim to reproduce the full Standard Model, full PDG particle corpus, or a microscopic derivation of electric charge from first principles.

The stored experiment is narrower.

It tests whether a controlled particle / transition corpus exhibits a recurring distinction between:

```text
charge value
```

and:

```text
charge route / closure structure
```

The strongest preserved contrast is:

```text
allowed expanded transitions
    → high route-transition persistence

mixed forbidden / constrained transitions
    → substantially reduced route-transition admissibility
```

even while the latter remain globally connected in the STRUC-PERC-I graph.

That is the empirical basis for the program’s boundary-route interpretation.
