# 01 — Plasma ↔ UNNS Translation Map

| Plasma physics object | UNNS interpretation | Possible measured proxy |
|---|---|---|
| L-mode | turbulent low-margin leakage regime | high fluctuation/turbulence signal; lower τ_E |
| L-H transition | admissibility threshold crossing | abrupt Dα drop, stored-energy rise, density rise, turbulence change |
| dithering phase | oscillatory boundary-crossing attempt | repeated brief transitions in Dα / turbulence signals |
| edge transport barrier | boundary-route preservation layer | suppressed edge transport; steep edge gradients |
| pedestal | compressed high-gradient boundary structure | pedestal top, pedestal width, ∇p, ∇n_e, ∇T_e |
| E×B shear | boundary reordering mechanism | radial electric field, velocity shear, Doppler backscattering |
| magnetic shear / shaping | geometry of admissible transport routes | q95, elongation, triangularity, X-point geometry |
| ELM | boundary overload / structural release | Dα spikes, heat/particle bursts, magnetic signatures |
| H-L back transition | loss of boundary admissibility | confinement drop, Dα recovery, pedestal collapse |
| confinement time τ_E | route-retention persistence | W/P_loss or device-provided τ_E |
| H98 factor | normalized confinement quality | τ_E / τ_E,98y2 |
