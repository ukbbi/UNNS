## Purpose

This file supports hardening provisional physical-window labels before stronger validation claims.

The reviewer should edit:

```text
outputs/reports/tokamark_physical_window_labels_HARDENING_REVIEW.csv
```

and save the accepted hardened version as:

```text
outputs/reports/tokamark_physical_window_labels_HARDENED_v0_1.csv
```

## Review rules

- Do not assign a physical label from `m_edge_conf(t)`.
- Use D-alpha, profile-gradient, soft-X, power/density context, and external references where available.
- Keep uncertain windows as `AMBIGUOUS` or `UNLABELABLE`.
- Reject labels that cannot be justified without UNNS columns.
- Treat `m_edge_conf_median_AUDIT_ONLY` as comparison data only.
