# B_PILOT_OBJECTS_I.txt
# STELLAR_BOUNDARY_DYNAMICS_I
# Phase B — Pilot Supernova Light-Curve Objects

PURPOSE:
Define the first controlled supernova sample for Phase B light-curve ladder
construction.

PHASE:
B_supernova_light_curves

SCHEMA:
B_light_curve_ladder_schema.csv

UNNS_ROLE:
These objects provide observed post-collapse brightness trajectories.
They are used to construct STRUC_PERC_I-compatible light-curve ladders:
rise → peak → decline → plateau/break/tail → late relaxation.

SELECTION_PRINCIPLE:
The first pilot set should include well-studied core-collapse supernovae with
available public photometry, known classification, and enough temporal coverage
to support canonical ladder construction.
