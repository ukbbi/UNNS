SOURCE_NOTES:
The ZTF public release page states that public images are released on a
60-day sliding window and that light curves are recalculated every 12 months.

The AWS Open Data registry describes ZTF light curves as PSF-fit photometry
detections extracted from single-exposure images at locations of Objects Table
detections. Related data are connected by object ID.

IRSA provides programmatic ZTF light-curve query access. Light curves are tagged
by ZTF object identifier and can also be retrieved by positional constraints.
