# FIELD-I v002 — Theorems (proofs)

Notation as in SPEC.md. "checked" = verified by field2.py in addition to the proof. Everything below is elementary.

## Lemma 0 (lattice lcm)
For reduced p/q, p'/q': (p/q)Z ∩ (p'/q')Z = (lcm(p,p')/gcd(q,q'))Z.  [Z-module of rationals; standard.]

## T6  Common future of a pair — proved, checked (F6.1, F8.2)
For r,s in F(x): the common values of the two routes at or after x are exactly x + jDelta, j >= 0, Delta = L^2/g.
Proof: routes pass x and then x + t s_N, x + t' s_N'. Steps are reduced (gcd(d^2,N)=1), so by Lemma 0 the common lattice is generated by lcm(d^2,d'^2)/gcd(N,N') = L^2/g. ∎

## T7  Integrality of the rendezvous index — proved, checked (F6.1)
h_rs = x/Delta_rs = (a/L^2)(g/b) is a positive integer; hence x_next = x(1+1/h), x < x_next <= 2x.
Proof: d^2 | a and d'^2 | a (T1) give L^2 | a. b = N/gcd(M,N) divides N, likewise N', so b | g. ∎

## T8  Collective rendezvous, coherence, and gcd H — proved, checked (F6.2, F6.3)
(a) The common future of all of F(x) is x + jDelta_coll, Delta_coll = lcm(d_i^2)/gcd(N_i).
(b) Coherence: Delta_coll = lattice-lcm of the pairwise Delta_rs (lcm over pairs of lcm(d_i^2,d_j^2) = lcm(d_i^2); gcd over pairs of gcd(N_i,N_j) = gcd(N_i), R >= 2; steps are reduced).
(c) gamma(x) = x/Delta_coll is a positive integer and gamma(x) = gcd H(x).
Proof of (c): x is a common multiple of the Delta_rs (x = h_rs Delta_rs), so x lies in Delta_coll Z and gamma in Z>0. Delta_coll = k_rs Delta_rs gives h_rs = gamma k_rs, so gamma | h_rs for all pairs, gamma | c := gcd H. Conversely x/c = Delta_rs (h_rs/c) is a common multiple, so x/c = m Delta_coll, m >= 1, i.e. gamma = c m >= c. Hence gamma = c. ∎
Consequence: the first collective meeting is x(1+1/gamma(x)); it equals 2x iff gamma = 1.

## T9  Every positive integer is a pair index — proved, checked (F6.5)
For x = 36h, d=2 and d'=3 lie in D(x) (4 | 36h, 9 | 36h), L = 6, g = gcd(1,2) = 1, Delta = 36, h_rs = h. ∎

## T10  Rigidity of the labelled structure (Regimes B) — proved, checked (F7.2-F7.4)
(a) N -> d^2/N is injective with numerator d^2, denominator N. Hence (v(r), v(F r)) determines the step, hence N = den(step), M = v(r)/step: the map r -> (v(r), v(F r)) is injective. Regime B carries exactly the label (M,N), nothing else.
(b) The structure (Occ, v, route-membership) has trivial automorphism group: an automorphism preserves values and maps route N onto a route with the same value set, which forces equal N (routes have distinct value sets; checked N<400). So any retention of route membership makes "relational" information coincide with label information.
Consequently label-blind structure can only be a value-level structure, whose automorphism group is Pi.

## T11  Regime A / orbit lemma — proved, checked (F7.1)
Pi acts transitively on the unordered pairs of every fibre with R >= 2. Hence a Pi-invariant function of an unordered pair is a function of the fibre alone. ∎

## T12  Admissible family (non-selection from A1-A3) — proved, checked (F8.1, F8.2)
A1-A3 (value-valued) hold for a pair operation iff * (r,s) = x + j(r,s) Delta_rs with j(r,s) in Z>0 (T6). Adding A4 requires j(r_i,s_i) = j(r,s); the constant maps j = 1,2,3,... , the maps j = 1+(min N mod 2) and others all satisfy A1-A4 and differ on every pair. A7 (minimality) selects j = 1; it is independent of A1-A4 (model j=2). ∎  [Outcome 2 for the constraint set A1-A4; Outcome 1 only after adding A7.]

## T13  Label-blind operations are collective — proved, checked (F8.1, F8.8)
If * is value-valued and satisfies A2, A3, A6, then * (r,s) = Y(x) depends on the fibre only (T11) and Y(x) - x is a positive common multiple of all Delta_rs, i.e. Y(x) = x + j(x) Delta_coll(x) = x(1 + j(x)/gamma(x)), j(x) in Z>0 free. Every such Y satisfies A2, A3, A6. With A7: Y_1(x) = x(1+1/gamma(x)). ∎
Regime C meaning: of the whole spectrum H(x) only gamma = gcd H(x) constrains a label-blind interaction; the rest of H(x) is classification.

## T14  No label-blind occurrence-valued operation — proved, checked (F8.3)
Let * assign to each pair an occurrence at a value y > x on both routes (A3), and be Pi-equivariant. Take pi in Sym(F(y)) (acting trivially on the other fibres, in particular on F(x), since y != x): pi(r*s) = (pi r)*(pi s) = r*s, so r*s is fixed by all of Sym(F(y)), forcing |F(y)| = 1. But F(y) contains the continuations of both r and s, |F(y)| >= 2. Contradiction. ∎

## T15  Incompatibility of stationarity and label-blindness — proved, checked (F8.6, F8.7)
No pair operation on the full domain A1 satisfies A3, A4 and A6 together.
Proof. Fix any x = a/b with a pair r,s in F(x); d,d',N,N',g,L,Delta as above; b | g (T7), so y_i = x+i Delta = (a g/b + i L^2)/g has denominator dividing g. Let p be a prime, p > max(g,L), p = 1 mod g (infinitely many, Dirichlet). Since p does not divide L, choose i >= 0 with a g/b + i L^2 = 0 mod p^2; then p^2 divides the numerator u of y_i, p does not divide g, and M'' = y_i(p-1)/p^2 = u(p-1)/(e p^2) is a positive integer (e | g | p-1): the route q = (M'', p-1) lies in F(y_i). Since p > L >= d, q differs from r_i, s_i (shifts of r,s by i periods; they lie in F(y_i) by T6).
A6 at y_i: *(r_i,s_i) = *(r_i,q) = Y(y_i). A3 for the pair (r_i,q): Y(y_i) = y_i + j Delta_{r_i q}, Delta_{r_i q} = (dp)^2/gcd(N,p-1), and gcd(N,p-1) <= N < p. So P := Y(y_i) - y_i has p^2 dividing its numerator in lowest terms. A4 for (r,s): *(r_i,s_i) = *(r,s) + iDelta, hence P = *(r,s) - x, a fixed positive rational independent of p. A fixed non-zero rational cannot have numerator divisible by p^2 for infinitely many primes. ∎
Corollary. Any grammar for interaction must choose: stationary route-aware (labels used), or label-blind collective (non-stationary).

## T16  Join on rational fibres — proved (T4 of v001, corrected), checked (F6.9, F8.4, F8.5)
For d,d' in D(a/b): lcm in D iff gcd(d,d') = 1 mod b; gcd(d,d') in D iff gcd >= 2 and gcd = 1 mod b (the value 1 is excluded by d >= 2; v001 stated the criterion without the exclusion).  If b = 1, D(m) is closed under lcm (join-semilattice; the meet may be 1). If b > 1 the join may fail to exist (x = 400/3, D = {4,10}). ∎
