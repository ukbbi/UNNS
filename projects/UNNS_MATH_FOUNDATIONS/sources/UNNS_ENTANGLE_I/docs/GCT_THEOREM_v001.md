# GCT Theorem Target v001

## Primary target
Derive an observable distribution
\[
P(A,B\mid a,b)
\]
from independently specified generative rules such that the resulting correlation law matches the singlet benchmark.

## Immediate theorem gate
Under the frozen v001 assumptions,
\[
P(A,B\mid a,b)=\int d\lambda\,\rho(\lambda)P(A\mid a,\lambda)P(B\mid b,\lambda).
\]
For this class,
\[
|S|\le 2
\]
for the CHSH expression.

## Meaning
v001 is therefore a **no-go audit**: if the current assumptions remain Bell-local, then the current assumptions do not explain entanglement.
