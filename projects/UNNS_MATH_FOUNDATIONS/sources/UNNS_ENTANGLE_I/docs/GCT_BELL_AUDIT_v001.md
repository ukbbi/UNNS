# GCT Bell Audit v001

The executable audit contains two separate tracks.

## Track 1 — Frozen local witness
A concrete Bell-local witness is used:
\[
A(a,\lambda)=\operatorname{sgn}(\cos(a-\lambda)),\qquad
B(b,\lambda)=-\operatorname{sgn}(\cos(b-\lambda)).
\]
This is not presented as the final UNNS generator. It is a witness that the locked assumptions remain inside the Bell-local class.

## Track 2 — Isolated quantum comparator
A quarantined singlet comparator computes the target benchmark. It is used only to show the gap between the Bell-local class and the quantum target.

## Audit questions
1. Are the distributions normalized?
2. Do local marginals remain independent of the remote setting?
3. What CHSH value does the local witness produce?
4. What CHSH value does the isolated singlet comparator produce?
5. Does the frozen v001 class already fail before any stronger UNNS claim is made?
