# Stable citation policy

After the local archive is verified and committed to GitHub, cite specific source files by a **full commit hash** or a dedicated frozen tag (for example `math-foundations-ref-v001`), not a mutable `main` URL.

Example structure (replace the placeholder hash with the actual published SHA):

`https://github.com/ukbbi/UNNS/blob/<COMMIT_SHA>/projects/UNNS_MATH_FOUNDATIONS/sources/FIELD-I/v012/THEOREMS.md`

Where needed, cite the theorem identifier (e.g. T72) alongside the URL, the associated RESULTS file, and any later correction. The reference library is **not** a claim of independent peer review or publication priority.

File history: `SOURCE_MAP.tsv` (original names, paths, SHA-256 and source provenance). `archives/ORIGINAL_USER_UPLOAD.zip` contains the latest upload verbatim and may be used to reconstruct its original directory names.
