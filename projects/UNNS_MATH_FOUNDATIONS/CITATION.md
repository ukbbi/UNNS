# Stable citation policy

Reference Collection v001 is GitHub commit `bb8b12d753c600c597feb00df17fe139c7cc65fa`. Cite specific source files by this **full commit hash** (or a dedicated frozen tag), not a mutable `main` URL.

Example:

`https://github.com/ukbbi/UNNS/blob/bb8b12d753c600c597feb00df17fe139c7cc65fa/projects/UNNS_MATH_FOUNDATIONS/sources/FIELD-I/v012/THEOREMS.md`

Where needed, cite the theorem identifier (e.g. T72) alongside the URL, the associated RESULTS file, and any later correction. The reference library is **not** a claim of independent peer review or publication priority.

File history: `SOURCE_MAP.tsv` (original names, paths, SHA-256 and source provenance). The original upload ZIP is not included in this repository; `SOURCE_MAP.tsv` records the original directory names.
