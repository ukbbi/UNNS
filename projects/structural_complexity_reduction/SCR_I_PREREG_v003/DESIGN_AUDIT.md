# v003 Design-Preservation Audit

Design-only seeds:

`2026100701`–`2026100705`

Pool size: 10,000 per seed.

The audit must establish all of the following before primary execution can unlock:

1. generator/adapter regression reproduces the previously frozen design counts;
2. independent target set is nonempty;
3. at least one target basin exists;
4. basin recall after G1→G4 is 1.000;
5. each basin retains ≥20 target-positive survivors;
6. minimum within-basin coverage is ≥0.95 at radius 0.25;
7. maximum centroid drift is ≤0.125;
8. target phenotype-stratum recall is 1.000;
9. no primary v003 seed has been evaluated.

The design audit is a calibration/falsification stage, not a primary outcome.
