# Nulls

## N1 — Rate-matched random pruning
For each cell, randomly retain exactly the same number of candidates as G1→G4. Recompute target-basin preservation under the same frozen basin oracle.

At N=10,000: 100 deterministic null replicates per seed.  
At N=2,500 and 40,000: 30 replicates per seed.

The primary SCR result does not depend on beating N1. N1 determines whether the observed preservation is specifically informative beyond generic redundancy at the same pruning rate.
