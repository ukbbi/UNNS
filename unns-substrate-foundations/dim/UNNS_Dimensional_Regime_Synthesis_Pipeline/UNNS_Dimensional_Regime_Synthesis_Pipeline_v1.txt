UNNS_Dimensional_Regime_Synthesis_Pipeline_v1
Overview

This archive contains the full UNNS Dimensional Regime Synthesis Pipeline, integrating multiple physical and synthetic domains into a unified structural analysis framework.

The goal of this pipeline is to:

Compute, compare, and analyze structural dimension (dim), scaling exponent (α), and margin (m) across diverse systems using a unified ladder-based representation.

Included Domains

The archive covers multiple domains processed under the same framework:

Atomic systems (Zeeman / spectral ladders)
Condensed matter / DFT materials
Cosmological datasets
Crystallographic structures (CIF → ladders)
Synthetic transition datasets

Core Components
1. unns_scaling_extractor.py

Main analysis engine.

For each ladder it computes:

α (scaling exponent)
m (margin proxy)
dim (effective dimension)
optional γ (spectral exponent)

This is the central measurement tool.

2. transition_generator.py

Generates deformation sweeps:

applies controlled transformations
tracks how α, m, and dim evolve

Used to detect:

transitions
stability regions
attractor behavior
3. Crystallography pipeline

Located in:

crystallography_cif_to_ladders_strict/

Handles:

CIF → ladder conversion
structural filtering
transition analysis
4. HTML visualization
unns_phase_space_v2.html

Provides:

regime mapping
clustering behavior
structural comparison across domains
What This Pipeline Produces

Across all domains, the pipeline extracts:

dimensional classification (dim = 1, 2, 3)
scaling behavior (α)
structural stability (m)
response to deformation
Key Findings Enabled by This Pipeline

This dataset supports the following observations:

1. Discrete vs continuous regimes
Atomic systems → discrete dimension jumps
Crystallography → continuous convergence
Cosmology → near-invariant structures
2. Attractor behavior

Many systems evolve toward:

stable margin values (m*)
stable dimensions (dim*)

independent of initial encoding

3. Encoding invariance

Different representations of the same system often converge to the same structural state.

4. Structural regimes

Systems naturally separate into regimes:

transition-driven
convergence-driven
inert / invariant
How to Use
Step 1 — Prepare ladders

Ensure input data is in ladder format (sorted sequences).

Step 2 — Run scaling extractor
python unns_scaling_extractor.py

Outputs results into:

output/
Step 3 — Run transition generator
python transition_generator.py

Produces deformation sweeps and transition datasets.

Step 4 — Analyze results
inspect CSV outputs
visualize with HTML interface
compare across domains
Notes
Some datasets may produce m = NaN
→ indicates insufficient or degenerate gap structure
Some pipelines (especially CIF-based) are strict by design
→ not all inputs will produce valid ladders
Cosmological ladders are often already in canonical form
→ require no conversion
