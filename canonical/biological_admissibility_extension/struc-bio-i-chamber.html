▶ Guide — How to use STRUC-BIO-I

What this chamber does

STRUC-BIO-I evaluates the UNNS admissibility inequality on a double-mutant epistasis graph: ρ = D(G) / C(G) ≤ 1, where D is the disorder (inversion count under fitness perturbation) and C is the compensation capacity (count of compensatory epistatic pairs). A clean result — all ρ ≤ 1 — constitutes structural admissibility of the fitness landscape. Any ρ > 1 is a genuine falsifier and is reported accurately.

Input files

Where to get the input files The fastest path is to download the pre-compiled QT45 pack from the input bundle: input_files.zip → open the QT45 MODE folder. Alternatively, run STRUC-BIO-II in any mode and use its EXPORT FOR STRUC-BIO-I button to generate all three files.
  • singles.csv — Single-mutant fitness table. Tab-separated, no header required. Format: LABEL<tab>FITNESS per row (e.g. G2A 0.0701). Hamming-0 (WT) rows are stripped automatically on load.
  • doubles.csv — Double-mutant fitness table. Tab-separated, no header required. Format: LABEL_A LABEL_B<tab>FITNESS_AB per row (e.g. G2A C3A 0.01349). Labels must match those in singles.csv — mismatches are warned and skipped.
  • wildtype.json — Optional. Provides the WT sequence and reference fitness for report annotation. Format: {"sequence": "…", "fitness": 0.0}. If omitted the chamber runs normally — only the report header is affected.

Running the chamber

  1. Click CHOOSE FILE under singles.csv and load your singles file. The filename turns green when accepted.
  2. Click CHOOSE FILE under doubles.csv and load your doubles file.
  3. Optionally load wildtype.json for annotated report output.
  4. Click ▶ RUN CHAMBER. The status indicator shows running… during the null-model Monte Carlo (1,000 fitness shuffles). Typical runtime: under 3 s.
  5. Results populate immediately: Core Law display, Structural Pressure metrics, Null Model and Epistasis charts, and the canonical JSON output.
  6. Click ↓ EXPORT JSON to download the full result bundle, or ↓ EXPORT REPORT for the annotated HTML report.

ρ ≤ 1 — Admissible (SATISFIED) The epistasis graph satisfies the USL bound. Disorder does not exceed compensation capacity. A high positive z-score indicates the result is well above the random-graph null — structural evidence is strong.
ρ > 1 — Violation (FAILED) Disorder exceeds compensation capacity. This is a genuine falsifier event. Reported accurately — never softened. Investigate the doubles file for data anomalies before concluding a structural violation.
Regime classification STABLE: ρ < 0.5  ·  BOUNDARY: 0.5 ≤ ρ ≤ 1.0  ·  BREAKDOWN: ρ > 1.0. The z-score measures the margin above the shuffled-fitness null distribution (1,000 runs, seed 42). High positive z = structurally significant result.
