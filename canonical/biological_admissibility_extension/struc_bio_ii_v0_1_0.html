QT45 MODE

1Drop singles file — tab-separated LABEL\tFITNESS rows, e.g. data_QT45_v2_singlemut_fitnes.txt
2Drop doubles file — LABEL_A LABEL_B\tFITNESS rows, e.g. data_QT45_v2_doublemut_fitnes.txt
3Optionally drop WT FASTA. If omitted, the hardcoded 45-nt QT45 master sequence is used automatically.
4Click COMPILE. All rows tagged source: measured. Malformed doubles and WT-row entries are skipped and counted.
Mutation labels must use DNA alphabet (T not U). Labels whose mutant base equals the WT base at that position (Hamming-0) are silently filtered on STRUC-BIO-I export.

FASTA POOL MODE

1Provide the WT sequence — drop a FASTA file or paste the sequence directly. RNA (U) is auto-converted to DNA (T).
2Drop the FL pool FASTA (full-length reads) and the IP pool FASTA (in-progress / selected reads). Filenames should end in _FL.fasta and _IP.fasta.
3Set pseudocount (default 0.5). Fitness is computed as log₂((IP + p) / (FL + p)) per mutant class.
4Click COMPILE. Sequences with 0 mutations → WT bucket; 1 → singles; 2 → doubles; 3+ → ignored (counted in diagnostics). All output tagged source: estimated.
Paired pool overlap in diagnostics is the fraction of doubles observed in both FL and IP. A low value means sparse coverage, not a parsing error — it is not namespace coverage.

QUASISPECIES MODE

1Drop the WT FASTA (master_sequence.fasta). RNA is converted to DNA automatically.
2Drop mutation tables (mutation_table_*.csv). Drop all at once for a full batch. Fidelity is inferred from filename (_960 → 0.960).
3Strongly recommended: also drop Empirical Singles and Empirical Doubles (e.g. the QT45 measured files). Without these, uniform matrices produce an identical fitness for every mutation — C=0 is guaranteed and the result is structurally uninformative.
4In hybrid mode: f_combined = f_measured + F̂(fidelity) where F̂ = log₂P(mut|wt,f) − log₂P(wt|wt,f). Doubles use the real measured epistasis E = f_ab − (f_a + f_b) plus fidelity-shifted singles. This produces a biologically structured landscape that varies with fidelity.
Landscape modes: hybrid = measured + fidelity correction (recommended). matrix-only = fidelity log-ratios only — intentionally degenerate for uniform matrices, useful only as a null baseline. The preflight panel shows which mode is active.
→EXPORT CANONICAL JSON — unified { meta, wt, singles, doubles, diagnostics } object. For archiving and inter-tool transfer.
→EXPORT FOR STRUC-BIO-I — produces three files: wildtype.json, singles.csv, doubles.csv. Hamming-0 entries are stripped automatically. Load these directly into STRUC-BIO-I.
→EXPORT BATCH BUNDLE — quasispecies only. Exports all fidelity levels as [{ fidelity, filename, canonical }, …]. Not directly loadable into STRUC-BIO-I — use canonical export per level for that.
Exports are blocked if validation finds errors (missing WT, duplicate labels). Hamming-0 warnings are informational — they do not block export, but affected rows are removed from the STRUC-BIO-I files.
